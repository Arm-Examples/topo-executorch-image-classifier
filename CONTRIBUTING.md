# Contribution guidelines

This Topo example accepts external contributions.

All accepted contributions are licensed under the [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0).

## Certify the origin of a contribution

Before this project accepts a contribution, you must certify its origin and give permission to use it. This project uses the [Developer Certificate of Origin (DCO) 1.1](https://developercertificate.org/) for this process.

Add a `Signed-off-by` line with your real name and email address to every commit message:

```text
Signed-off-by: <first-name> <last-name> <email-address>
```

Use the `-s` option to add this line when you create a commit:

```bash
git commit -s
```

Pseudonyms and anonymous contributions are not accepted.

## Submit a contribution

1. Create a pull request from your fork. For instructions, see [Creating a pull request from a fork](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/creating-a-pull-request-from-a-fork).
2. Address review feedback from the project maintainers.
3. Ensure that all formatting checks and tests pass.

Only reviewed contributions can be merged into the `main` branch.
